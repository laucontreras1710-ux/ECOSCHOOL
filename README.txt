ECOSCHOOL - versión escolar
==============================

Esta es una primera versión funcional de la app.

Archivos:
- index.html: aplicación completa.
- manifest.json: permite instalarla como app cuando se publique con HTTPS.
- sw.js: funcionamiento básico offline.

Para probarla:
1. Abre index.html en un navegador.
2. Para publicarla gratis, sube estos tres archivos a un repositorio de GitHub y activa GitHub Pages.
3. Cuando esté publicada con HTTPS, desde Chrome en Android podrás usar "Añadir a pantalla de inicio" / "Instalar aplicación".

La app guarda los puntos y el progreso en el dispositivo usando almacenamiento local.
